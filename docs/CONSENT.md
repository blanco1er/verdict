# Sample selfie

`public/sample/selfie.jpg` is a real selfie used as the app's sample photo, in the demo video and on the project page.
The owner of the project confirmed on 30 Oct 2026 that the person in it agreed to this use.
It was analysed once with the live YouCam AI Skin Analysis API (12 units, 8 concerns, SD); the scores and the
returned masks are stored in `src/lib/live/sample-analysis.json` and `public/sample/masks/`, so the sample replays a
real result without spending units. No other personal data is stored.
